# رتّل — منصة تعلّم القرآن وعلومه

تطبيق ويب: **HTML + CSS + JavaScript** في الواجهة، و**Node.js + Express + SQLite** في الخادم.
المحتوى مبني على تطبيق «رتّل» (التجويد برواية ورش + فهرس الحفظ من كتاب «سور وآيات فاضلات») وموسَّع.

## التجربة محليًا (قبل أي نشر)

يلزم Node.js **22.13 أو أحدث** (SQLite مدمج فيه، لا حاجة لتثبيت شيء آخر).

```bash
cd rattil
npm install
npm start
```

افتح http://localhost:3000 . عند أول تشغيل يُطبع في الطرفية **رقم هاتف المشرف وكلمة سره** (تظهر مرة واحدة).
لتحديدها بنفسك:

```bash
ADMIN_PHONE=0600000000 ADMIN_PASSWORD='كلمة-سر-قوية' ADMIN_NAME='المشرف' npm start
```

للتحقق من سلامة المحتوى (4200 سؤال): `npm run check`

## ما الذي في التطبيق؟

| | |
|---|---|
| **التسجيل** | الاسم + الهاتف + كلمة سر مرتين. تظهر رسالة «انتظر التأكيد أو تواصل مع المسؤول». لا يدخل المحتوى إلا بعد تفعيل المشرف. |
| **البطائق (6 أقسام)** | التجويد (4 مراحل · 19 فرعًا) · علوم القرآن (5) · الحفظ · الفقه المالكي (8) · الحديث (5) · المعاملات (5). |
| **كل فرع** | **10 مراحل × 10 أسئلة** (مثلًا «النون الساكنة والتنوين» له 100 سؤال). النجاح بـ 8/10 يفتح المرحلة التالية، والنجوم: 8→★ 9→★★ 10→★★★. |
| **تنوّع الأسئلة** | اختيار من متعدد، صح/خطأ، تكملة فراغات من بنك كلمات (إملاء)، ترتيب كلمات، ترتيب حروف، توصيل عبارات، «اختر السؤال المناسب». الصعوبة تزداد بين المراحل (خيارات أكثر، فراغات أكثر، جمل أطول). |
| **الحفظ** | وحدات «سور وآيات فاضلات» بترتيب الكتاب. **المشرف وحده** يحدّد: لم يبدأ / قيد الحفظ / محفوظ (لكل وحدة، أو للكل دفعة واحدة). |
| **الإدارة** | تفعيل/إيقاف/حذف الحسابات، كلمة سر جديدة (يُسلَّمها المشرف للمستخدم)، تفاصيل تقدّم كل مستخدم في كل فرع ومرحلة والحفظ، وترتيب الجميع. |
| **لوحة الشرف** | عامة، أو لكل قسم، أو لكل فرع، أو للحفظ. المشرف يشغّلها للمستخدمين أو يبقيها له وحده (الإعدادات ← لوحة الشرف). تُعرض الأسماء فقط، لا الأرقام. |

## الأمان والبيانات

- **SQLite** في `data/rattil.db`. **الاسم والهاتف مشفّران** (AES-256-GCM)، والبحث/منع التكرار عبر بصمة HMAC للرقم. كلمات السر `scrypt` مملّحة.
- مفتاح التشفير: متغير `DATA_KEY` (64 حرف hex) أو يُولَّد تلقائيًا في `data/secret.key`. **احفظ نسخة منه**، فبدونه لا تُفكّ البيانات. لا ترفع `data/` إلى GitHub (مستثناة في `.gitignore`).
- نسيت كلمة السر؟ المشرف يولّد كلمة جديدة من لوحة الإدارة.
- الجلسات في كوكي `HttpOnly`، تحديد محاولات الدخول، الاختبارات تُصحَّح في الخادم (الأجوبة لا تُرسَل للمتصفح قبل التسليم)، ولا يمكن تسليم الاختبار نفسه مرتين.

## قبل النشر على الإنترنت

1. شغّله خلف HTTPS (Nginx/Caddy) مع `NODE_ENV=production` و`TRUST_PROXY=1`.
2. عيّن `ADMIN_PASSWORD` و`DATA_KEY` ثابتين، وخذ نسخة احتياطية دورية من مجلد `data/`.
3. استضافة تدعم Node.js مع قرص دائم (VPS، Railway، Render مع Disk…). لا تصلح الاستضافات الثابتة (Netlify/GitHub Pages) لأن هناك خادمًا وقاعدة بيانات.

## إضافة وتعديل المحتوى

- التجويد: `content/legacy-tajweed.js` — **كل فرع فيه 8–9 أسئلة اختيار فقط**، فتتكرر الحقائق أكثر في المراحل العشر. أضف أسئلة `M(...)` لكل بطاقة لتنويع أكبر (الأفضل 15–20 لكل فرع).
- بقية الأقسام: `content/sections-*.js` (سؤال، الجواب، 3 أجوبة خاطئة). جمل `lesson` تُستعمل في الدرس وأسئلة الإملاء والترتيب.
- فهرس الحفظ: `content/legacy-hifz.js` (لا تغيّر `key` بعد بدء المستخدمين).

## تنبيه علمي مهم

محتوى **الفقه والحديث وعلوم القرآن والمعاملات كتبته بصيغة أولية** على المذهب المالكي، وتجويد ورش مأخوذ من «رتّل». **يجب أن يراجعه شيخ مجاز** قبل اعتماده. بنية الأسئلة تسهّل التصحيح بتعديل سطر واحد.
